## 核心特性
- **精准定时** — 通过直观的圆环拖拽滑块设置最长 60 分钟的倒计时。
- **自动锁屏** — 定时结束时，通过无障碍服务或设备管理员自动锁定屏幕。
- **自动停止媒体** — 倒计时结束后暂停所有媒体播放。
- **后台可靠运行** — 即使将应用从任务列表划掉，定时器仍会继续计时。
- **常驻通知** — 在通知栏实时显示倒计时，并提供快捷操作按钮。
- **Material 3 设计** — 支持动态取色与深/浅色主题，界面简洁现代。
- **无广告、无追踪** — 完全开源，不收集任何数据。

## 技术栈
- **开发语言** — Kotlin
- **UI 框架** — Jetpack Compose
- **设计系统** — Material Design 3

## 使用说明
1. 启动「睡眠定时器」应用。
2. 拖拽圆环滑块或点击预设时间，设置倒计时时长。
3. 点击播放按钮启动定时器。
4. 应用会在后台倒计时。倒计时归零后，将自动锁屏或停止媒体播放。
